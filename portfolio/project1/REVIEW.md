## 1. High-Level Architecture Overview

### 1.1 Design Goals & System Topology
`project_1` is an ultra-low-latency, tick-level (L2/L3) event-driven market microstructure backtester designed to simulate slippage and queue position at microsecond resolution across three isolated processes sharing a single POSIX shared-memory (`mmap`) contract:

```text
Rust Data Router  ──write──▶  POSIX shm ring buffer  ──poll──▶  C++ Core Engine  ──pybind11──▶  Python
(tokio, WebSocket)            (SPSC, 64B slots)                 (LOB, fills, PnL)             (research)
```

* **IPC Latency Target**: `< 1 μs` from Rust receipt (`local_ts`) to C++ Limit Order Book (LOB) update.
* **Throughput Target**: `10M messages/sec` sustained.
* **Memory Constraint**: `0` dynamic heap allocations (`new`/`malloc`/`free`) in the C++ simulation loop, verified via Valgrind.

## 2. Low-Latency Performance & Bottleneck Analysis

### 2.1 Broken Consumer Index Caching (`ring.hpp:208-219`)
* **Issue**: `DESIGN.md` §3 and §4 specify that the consumer must keep a private `cached_write_idx` and only issue a cross-core `Acquire` load of `prod.write_idx` when `read_idx == cached_write_idx`. Currently, `Consumer::available()` unconditionally performs `cached_write_idx_ = h_->prod.write_idx.load(std::memory_order_acquire)` on every call, never reading the cached value.
* **Impact**: When draining capped batches (`n > max_batch` in `ring_bench.cpp:119`) or popping single events (`batch = 1` in `--mode lat`), every loop iteration triggers an unnecessary cross-core MESI read on the producer's cache line even when unconsumed items are already known to be available.

### 2.2 `Counters` False Sharing & Hot-Loop `LOCK XADD` (`ring_bench.cpp:39-84`)
* **Issue**: `struct Counters` packs seven `std::atomic<uint64_t>` counters (56 bytes) into a single unaligned struct shared by pointer between `produce()` and `consume()`. Inside the producer hot loop (`ring_bench.cpp:74-81`), full-ring stalls call `c->full_stalls.fetch_add(1, std::memory_order_relaxed)` and `c->full_cycles.fetch_add(..., std::memory_order_relaxed)`.
* **Impact**:
  1. On x86-64, `fetch_add` (even with `memory_order_relaxed`) compiles to a `LOCK XADD` instruction, acting as a full hardware memory barrier that drains the core's store buffer right before `rdtscp_now()` and `p.publish()`.
  2. Producer writes to `full_stalls` and `full_cycles` share a 64-byte cache line with consumer writes (`gaps`, `recv`, `polls`, `queued`), causing false sharing.

### 2.3 Partial Cache-Line Write & Read-For-Ownership (RFO) Penalty (`ring_bench.cpp:83-88`)
* **Issue**: In `produce()`, the producer writes only 16 bytes (`e->seq` and `e->t_produce`) of the 64-byte `BenchEvent` slot, leaving `uint64_t pad[6]` (48 bytes) unwritten.
* **Impact**: As noted in `DESIGN.md` §12, when the ring wraps around onto cache lines evicted to L3/DRAM, writing 16 of 64 bytes forces a Read-For-Ownership (RFO) transfer of the existing cache line to merge the untouched 48 bytes. Writing the full 64-byte struct reflects the actual `MarketEvent` workload.

### 2.4 `PingPong` Struct Over-Padding (`noise_floor.cpp:77-82`)
* **Issue**: `PingPong` is declared `alignas(128)` with `std::atomic<uint64_t> seq{0};` (8B), `uint64_t stamp{0};` (8B), and `char pad[128 - sizeof(std::atomic<uint64_t>)]{};` (120B).
* **Impact**: Omitting `sizeof(stamp)` from the padding calculation yields 136 bytes of fields, which `alignas(128)` pads out to **256 bytes** (`sizeof(PingPong) == 256`) instead of the intended 128-byte L2 prefetcher pair.

### 2.5 Build Flag Downgrade (`CMakeLists.txt:14`) & Struct Padding (`instruments_generated.hpp:13-20`)
* **Issue**: `CMakeLists.txt` sets `CMAKE_BUILD_TYPE` to `Release` (`-O3`), but `BENCH_FLAGS` explicitly passes `-O2`, overriding `-O3`. Additionally, `mkt::Instrument` places `int64_t tick_units` between two `uint8_t` fields, adding 14 bytes of implicit padding per struct (`sizeof(Instrument) == 40`; reordering brings it to `32`).

## 3. Concurrency Safety & Bug Detection

### 3.1 CRITICAL: Missing Closing Brace `};` in Generated C++ Header (`tools/gen_instruments.py:67-76` & `instruments_generated.hpp:24-31`)
* **Bug**: `tools/gen_instruments.py` opens `inline constexpr Instrument kInstruments[{n} + 1] = {` but never emits the closing `};` before `} // namespace mkt`.
* **Consequence**: `instruments_generated.hpp` contains a fatal C++ syntax error that has gone unnoticed only because none of the existing three benchmark targets include it yet.

### 3.2 C++ Data Race (UB) & Premature Abort in `ring::init()` / `ring::attach()` (`ring.hpp:95-150`)
* **Bug**: `ring::init()` constructs `Header` via placement `new` (non-atomically zeroing 384 bytes), populates non-atomic fields (`version`, `slot_bytes`, `capacity`, `clock_id`), and finally publishes `magic` with `memory_order_release`. However, `ring::attach()` uses non-short-circuiting `&=` across all checks and unconditionally reads `h->stat.version`, `slot_bytes`, `capacity`, and `clock_id` even when `magic != kMagic`.
* **Consequence**:
  1. If the router attaches concurrently while `init()` is running (`magic == 0`), reading the non-atomic fields without observing `magic == kMagic` violates the happens-before relation, causing a **C++ Data Race (Undefined Behavior)**.
  2. If `magic == 0`, `attach()` immediately calls `std::abort()` instead of allowing the router to retry as required by `DESIGN.md` §6.

### 3.3 Unchecked `kSchemaVersion` in `ring::Header` (`ring.hpp:48-56`, `market_event.hpp:18`)
* **Bug**: `market_event.hpp` states that `kSchemaVersion` is written into the ring header so stale segments are rejected, but `ring::Header::StaticBlock` leaves `uint32_t reserved` unused and only checks `ring::kVersion`.
* **Consequence**: Any semantic or field-order change to `MarketEvent` that preserves its 64-byte size will not be caught by `attach()`.

### 3.4 Cross-Language Aliasing (Rust `noalias` UB) & Missing Header Offset Assertions (`ring.hpp:73-88`, `layout_dump.cpp:14-21`)
* **Bug**:
  1. `ring.hpp` and `layout_dump.cpp` only check the outer block offsets (`0`, `128`, `256`) and do not verify `sizeof(std::atomic<T>) == sizeof(T)` or the internal field offsets of `StaticBlock`, `ProducerBlock`, and `ConsumerBlock`.
  2. In Rust, forming `&mut MarketEvent` or `&mut Header` over shared memory concurrently mapped by another process is immediate Undefined Behavior under LLVM's `noalias` rules. The Rust router must use raw pointer writes (`core::ptr::write`) for slots and shared references (`&Header`) with `AtomicU64`/`AtomicU32` for header synchronization.
  3. `ring::Producer` lacks a method to increment `dropped_count` when operating under the live-feed drop policy (`DESIGN.md` §5).

### 3.5 Comment Contradiction on `instrument_id = 0` (`market_event.hpp:50`)
* **Bug**: `market_event.hpp:50` states `0 is valid`, contradicting `DESIGN.md` §13, `instruments.csv`, and `router/src/event.rs:38` (`0 is reserved as invalid`).

### Patch 2: `ring.hpp:44-235` (Fix Consumer Caching, `try_attach` Race, `schema_version`, and Offset Asserts)

```cpp
// ring.hpp:44-235
struct Header {
    // Written at init, read-only for the life of the segment. Shares no line
    // with anything mutable, so the validation attach() performs never touches
    // a line either side is writing.
    struct alignas(kRegionBytes) StaticBlock {
        std::atomic<uint64_t> magic; // atomic so that init can publish it last
        uint32_t version;
        uint32_t slot_bytes;
        uint64_t capacity; // power of two, validated at init
        uint32_t clock_id;
        uint32_t schema_version;
    } stat;

    // Producer-written. dropped_count moves only on a drop and producer_state
    // twice per run, so they cost the consumer -- which reads all three and
    // writes none -- nothing here, and save a region.
    struct alignas(kRegionBytes) ProducerBlock {
        std::atomic<uint64_t> write_idx;
        std::atomic<uint64_t> dropped_count;
        std::atomic<uint32_t> producer_state;
    } prod;

    // Consumer-written.
    struct alignas(kRegionBytes) ConsumerBlock {
        std::atomic<uint64_t> read_idx;
    } cons;
};

inline constexpr size_t kHeaderBytes = sizeof(Header);

static_assert(sizeof(std::atomic<uint64_t>) == sizeof(uint64_t), "FFI layout mismatch");
static_assert(sizeof(std::atomic<uint32_t>) == sizeof(uint32_t), "FFI layout mismatch");
static_assert(sizeof(Header::StaticBlock) == kRegionBytes,
              "static block must own its region");
static_assert(sizeof(Header::ProducerBlock) == kRegionBytes,
              "producer block must own its region");
static_assert(sizeof(Header::ConsumerBlock) == kRegionBytes,
              "consumer block must own its region");
static_assert(sizeof(Header) == 3 * kRegionBytes,
              "header is exactly three regions");
static_assert(offsetof(Header, stat) == 0, "static block at 0");
static_assert(offsetof(Header, prod) == kRegionBytes, "producer block at 128");
static_assert(offsetof(Header, cons) == 2 * kRegionBytes,
              "consumer block at 256");

static_assert(offsetof(Header::StaticBlock, magic) == 0, "layout drift");
static_assert(offsetof(Header::StaticBlock, version) == 8, "layout drift");
static_assert(offsetof(Header::StaticBlock, slot_bytes) == 12, "layout drift");
static_assert(offsetof(Header::StaticBlock, capacity) == 16, "layout drift");
static_assert(offsetof(Header::StaticBlock, clock_id) == 24, "layout drift");
static_assert(offsetof(Header::StaticBlock, schema_version) == 28, "layout drift");

static_assert(offsetof(Header::ProducerBlock, write_idx) == 0, "layout drift");
static_assert(offsetof(Header::ProducerBlock, dropped_count) == 8, "layout drift");
static_assert(offsetof(Header::ProducerBlock, producer_state) == 16, "layout drift");

static_assert(offsetof(Header::ConsumerBlock, read_idx) == 0, "layout drift");

static_assert(kHeaderBytes % kSlotBytes == 0,
              "slot array must start slot-aligned");
static_assert(std::atomic<uint64_t>::is_always_lock_free,
              "a lock in the header is not a ring");
static_assert(std::atomic<uint32_t>::is_always_lock_free,
              "a lock in the header is not a ring");

inline constexpr size_t segment_bytes(uint64_t capacity) {
    return kHeaderBytes + static_cast<size_t>(capacity) * kSlotBytes;
}

// The engine creates and sizes the segment; the router only ever attaches (§6).
inline Header *init(void *base, uint64_t capacity, ClockId clock,
                    uint32_t schema_version = 1) {
    if (capacity == 0 || (capacity & (capacity - 1)) != 0) {
        std::fprintf(stderr, "ring: capacity %llu is not a power of two\n",
                     static_cast<unsigned long long>(capacity));
        std::abort();
    }
    if (reinterpret_cast<uintptr_t>(base) % kRegionBytes != 0) {
        std::fprintf(stderr, "ring: segment base is not %zu-byte aligned\n",
                     kRegionBytes);
        std::abort();
    }

    Header *h = new (base) Header{};
    h->prod.write_idx.store(0, std::memory_order_relaxed);
    h->prod.dropped_count.store(0, std::memory_order_relaxed);
    h->prod.producer_state.store(
        static_cast<uint32_t>(ProducerState::NotStarted),
        std::memory_order_relaxed);
    h->cons.read_idx.store(0, std::memory_order_relaxed);
    h->stat.version = kVersion;
    h->stat.slot_bytes = kSlotBytes;
    h->stat.capacity = capacity;
    h->stat.clock_id = static_cast<uint32_t>(clock);
    h->stat.schema_version = schema_version;

    // Magic goes last with a Release. A router attaching mid-init would
    // otherwise validate against a capacity that has not been written yet and
    // pass, which is the exact silent failure §6 exists to prevent.
    h->stat.magic.store(kMagic, std::memory_order_release);
    return h;
}

namespace detail {
inline bool check(const char *field, uint64_t got, uint64_t want) {
    if (got == want) return true;
    std::fprintf(
        stderr,
        "ring: %s mismatch -- segment has %llu, this build expects %llu\n",
        field, static_cast<unsigned long long>(got),
        static_cast<unsigned long long>(want));
    return false;
}
} // namespace detail

// Returns nullptr if magic == 0 (init has not published yet) so an attaching
// process can retry safely without reading uninitialized non-atomic fields.
inline Header *try_attach(void *base, uint64_t expect_capacity,
                          ClockId expect_clock, uint32_t expect_schema = 1) {
    Header *h = static_cast<Header *>(base);
    const uint64_t magic = h->stat.magic.load(std::memory_order_acquire);
    if (magic == 0) return nullptr;

    bool ok = detail::check("magic", magic, kMagic);
    if (ok) {
        ok &= detail::check("version", h->stat.version, kVersion);
        ok &= detail::check("slot_bytes", h->stat.slot_bytes, kSlotBytes);
        ok &= detail::check("capacity", h->stat.capacity, expect_capacity);
        ok &= detail::check("clock_id", h->stat.clock_id,
                            static_cast<uint32_t>(expect_clock));
        ok &= detail::check("schema_version", h->stat.schema_version,
                            expect_schema);
    }
    if (!ok) {
        std::fprintf(stderr, "ring: refusing to attach. This is a stale "
                             "segment or a version-skewed "
                             "binary; continuing would corrupt every number "
                             "downstream rather than "
                             "produce an error.\n");
        std::abort();
    }
    return h;
}

inline Header *attach(void *base, uint64_t expect_capacity,
                      ClockId expect_clock, uint32_t expect_schema = 1) {
    Header *h = try_attach(base, expect_capacity, expect_clock, expect_schema);
    if (h == nullptr) {
        std::fprintf(stderr, "ring: segment magic is 0 (uninitialized)\n");
        std::abort();
    }
    return h;
}

class Producer {
  public:
    explicit Producer(Header *h) noexcept
        : h_(h), slots_(reinterpret_cast<uint8_t *>(h) + kHeaderBytes),
          capacity_(h->stat.capacity), mask_(h->stat.capacity - 1),
          write_idx_(h->prod.write_idx.load(std::memory_order_relaxed)),
          cached_read_idx_(h->cons.read_idx.load(std::memory_order_acquire)),
          dropped_(h->prod.dropped_count.load(std::memory_order_relaxed)) {
        h_->prod.producer_state.store(
            static_cast<uint32_t>(ProducerState::Running),
            std::memory_order_release);
    }

    uint8_t *claim() noexcept {
        if (write_idx_ - cached_read_idx_ == capacity_) {
            cached_read_idx_ =
                h_->cons.read_idx.load(std::memory_order_acquire);
            if (write_idx_ - cached_read_idx_ == capacity_) return nullptr;
        }
        return slots_ + (write_idx_ & mask_) * kSlotBytes;
    }

    void publish() noexcept {
        h_->prod.write_idx.store(++write_idx_, std::memory_order_release);
    }

    void record_drop() noexcept {
        h_->prod.dropped_count.store(++dropped_, std::memory_order_relaxed);
    }

    void finish() noexcept {
        h_->prod.producer_state.store(
            static_cast<uint32_t>(ProducerState::Exited),
            std::memory_order_release);
    }

  private:
    Header *h_;
    uint8_t *slots_;
    uint64_t capacity_;
    uint64_t mask_;
    uint64_t write_idx_;
    uint64_t cached_read_idx_;
    uint64_t dropped_;
};

class Consumer {
  public:
    explicit Consumer(Header *h) noexcept
        : h_(h), slots_(reinterpret_cast<uint8_t *>(h) + kHeaderBytes),
          mask_(h->stat.capacity - 1),
          read_idx_(h->cons.read_idx.load(std::memory_order_relaxed)),
          cached_write_idx_(h->prod.write_idx.load(std::memory_order_acquire)) {}

    // Consults the shared producer line only when the cached copy says the
    // ring is empty (§3, §4).
    uint64_t available() noexcept {
        if (read_idx_ == cached_write_idx_) {
            cached_write_idx_ =
                h_->prod.write_idx.load(std::memory_order_acquire);
        }
        return cached_write_idx_ - read_idx_;
    }

    // Forces an Acquire reload of write_idx (e.g. on producer exit check).
    uint64_t refresh_available() noexcept {
        cached_write_idx_ = h_->prod.write_idx.load(std::memory_order_acquire);
        return cached_write_idx_ - read_idx_;
    }

    const uint8_t *peek() const noexcept {
        return slots_ + (read_idx_ & mask_) * kSlotBytes;
    }

    void pop() noexcept { ++read_idx_; }

    void commit() noexcept {
        h_->cons.read_idx.store(read_idx_, std::memory_order_release);
    }

  private:
    Header *h_;
    uint8_t *slots_;
    uint64_t mask_;
    uint64_t read_idx_;
    uint64_t cached_write_idx_;
};
```

### Patch 3: `ring_bench.cpp:39-250` (Isolate `Counters`, Remove Hot-Loop `fetch_add`, Write Full 64B Slot)

```cpp
// ring_bench.cpp:39-146
struct Counters
{
    struct alignas(ring::kRegionBytes)
    {
        std::atomic<uint64_t> sent{0};
        std::atomic<uint64_t> full_stalls{0};
        std::atomic<uint64_t> full_cycles{0};
    } prod;

    struct alignas(ring::kRegionBytes)
    {
        std::atomic<uint64_t> recv{0};
        std::atomic<uint64_t> gaps{0};
        std::atomic<uint64_t> polls{0};
        std::atomic<uint64_t> queued{0};
    } cons;
};

void produce(ring::Header *h, int cpu, uint64_t events, uint64_t period_cycles, bool stamp, Counters *c)
{
    if (!pin_to(cpu)) std::fprintf(stderr, "ring_bench: producer failed to pin to cpu %d\n", cpu);
    ring::Producer p(h);

    uint64_t full_stalls = 0;
    uint64_t full_cycles = 0;
    const uint64_t t0 = rdtscp_now();
    for (uint64_t i = 0; i < events; ++i)
    {
        if (period_cycles != 0)
        {
            const uint64_t deadline = t0 + i * period_cycles;
            while (rdtscp_now() < deadline) _mm_pause();
        }

        uint8_t *slot = p.claim();
        if (slot == nullptr)
        {
            const uint64_t t_stall = rdtscp_now();
            ++full_stalls;
            do
            {
                _mm_pause();
                slot = p.claim();
            } while (slot == nullptr);
            full_cycles += rdtscp_now() - t_stall;
        }

        BenchEvent *e = reinterpret_cast<BenchEvent *>(slot);
        *e = BenchEvent{
            .seq = i,
            .t_produce = stamp ? rdtscp_now() : 0,
            .pad = {0, 0, 0, 0, 0, 0}
        };
        p.publish();
    }

    c->prod.sent.store(events, std::memory_order_relaxed);
    c->prod.full_stalls.store(full_stalls, std::memory_order_relaxed);
    c->prod.full_cycles.store(full_cycles, std::memory_order_relaxed);
    p.finish();
}

void consume(ring::Header *h, int cpu, bool measure, uint64_t max_batch, std::vector<uint64_t> *raw, Counters *c)
{
    if (!pin_to(cpu)) std::fprintf(stderr, "ring_bench: consumer failed to pin to cpu %d\n", cpu);
    ring::Consumer q(h);

    uint64_t expect = 0;
    uint64_t recv = 0;
    uint64_t gaps = 0;
    uint64_t nmeas = 0;
    uint64_t polls = 0;
    uint64_t queued = 0;

    while (true)
    {
        uint64_t n = q.available();
        if (n == 0)
        {
            if (h->prod.producer_state.load(std::memory_order_acquire) == static_cast<uint32_t>(ring::ProducerState::Exited) && q.refresh_available() == 0) break;
            _mm_pause();
            continue;
        }

        const uint64_t t_consume = rdtscp_now();
        ++polls;
        if (n > 1) ++queued;
        if (n > max_batch) n = max_batch;

        for (uint64_t k = 0; k < n; ++k)
        {
            const BenchEvent *e = reinterpret_cast<const BenchEvent *>(q.peek());
            if (e->seq != expect) ++gaps;
            expect = e->seq + 1;
            if (measure && k == 0 && nmeas < raw->size()) (*raw)[nmeas++] = t_consume - e->t_produce;
            ++recv;
            q.pop();
        }

        q.commit();
    }

    c->cons.recv.store(recv, std::memory_order_relaxed);
```
