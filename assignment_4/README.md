## 로컬 실행 방법

Express 5는 Node.js 18 이상이 필요합니다. 아래 명령은 모두 프로젝트 루트(이 README가 있는 폴더)에서 실행합니다. `views/`, `public/`, `.env`를 현재 폴더 기준으로 찾기 때문입니다.

1. **Node.js와 PostgreSQL 설치.** [Node.js](https://nodejs.org/) LTS와 [PostgreSQL](https://www.postgresql.org/download/)을 설치하고 PostgreSQL 서버를 실행합니다.

2. **DB 사용자와 데이터베이스 생성.** 이름은 자유롭게 정해도 됩니다. Linux의 예:
    ```bash
    sudo -u postgres createuser -P library        # 새 비밀번호를 입력
    sudo -u postgres createdb -O library library
    ```
    Windows나 macOS에서는 `psql`로 접속해 다음을 실행해도 됩니다.
    ```sql
    CREATE USER library WITH PASSWORD '<비밀번호>';
    CREATE DATABASE library OWNER library;
    ```

3. **패키지 설치.**
    ```bash
    npm install
    ```

4. **`.env` 작성.** `.env.example`을 `.env`로 복사한 뒤, 2단계에서 만든 접속 정보로 고칩니다.
    ```bash
    cp .env.example .env
    ```
    ```
    DATABASE_URL="postgresql://{user}:{password}@{host}:{port}/{database}"
    ```
    예: `DATABASE_URL="postgresql://library:<비밀번호>@localhost:5432/library"`

5. **DB 초기화.** 9개 테이블을 지우고 다시 만든 뒤 시드 데이터를 넣습니다. 전체가 하나의 트랜잭션이라 중간에 실패하면 기존 테이블은 그대로 남고, 성공하면 테이블별 행 수를 출력합니다.
    ```bash
    npm run db:init
    ```

6. **서버 실행.** <http://localhost:3000> 으로 접속합니다.
    ```bash
    npm start
    ```

시드의 대출·예약 날짜는 `db:init`을 실행한 날을 기준으로 계산됩니다. 연체 상태 등이 의도대로 보이도록 시연이나 채점 직전에 `npm run db:init`을 다시 실행하는 것을 권장합니다. 세션은 메모리에 저장되므로 서버를 다시 시작하면 모두 로그아웃됩니다.

## 기능

### 필수 기능

| 기능 | 경로 | 내용 |
|---|---|---|
| 회원가입·로그인 | `/register`, `/login`, `/logout` | ID는 영문·숫자·밑줄 3~20자. 관리자 가입은 학번 코드 필요. 비밀번호는 scrypt + 솔트로 저장 |
| 도서 목록 | `/books` | 제목·저자·카테고리·전체 수량·대출 가능 수량. 제목·저자·카테고리로 검색과 정렬. Show Instances로 복본별 대출자와 대출일 확인 |
| 인기 차트 | `/charts` | 최근 3개월 대출을 도서(모든 복본 합산)와 저자별로 집계. 카테고리별 인기 도서 |
| 대출·반납 | 도서 목록의 Borrow / Return | 동시에 최대 3권, 같은 책 2권 동시 대출 불가, 연체(대출 후 7일 이상 미반납) 중이면 대출 불가 |
| 대출 기록 | `/borrowings` | 정확히 어떤 복본(#번호)을 빌렸는지와 대출일·반납일 |
| 도서 관리 (관리자) | `/books/add`, 복본 Delete | 새 저자·카테고리를 입력해 바로 추가, 한 책에 여러 카테고리. 대출 중인 복본은 삭제 불가, 마지막 복본을 지우면 도서도 삭제 |
| 카테고리 관리 (관리자) | `/categories` | 추가(대소문자 무시 중복 금지)와 삭제. 삭제해도 도서는 다른 카테고리를 유지 |
| 회원 관리 (관리자) | `/users` | 회원 목록, ID·역할로 검색 |

| 기능 | 경로 | 내용 |
|---|---|---|
